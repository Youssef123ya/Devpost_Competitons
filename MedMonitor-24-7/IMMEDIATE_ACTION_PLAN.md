## 🎯 خطوات الإجراء الفوري (ترتيب الأولويات)

### المرحلة 1: اختبار الجودة الحالية (5 دقائق)

```bash
ULTRA_QUALITY_DIAGNOSTIC.bat
```

اختر:
```
2. Test ULTRA Quality Enhancement
```

**ماذا تبحث عنه:**
- [ ] هل الأرقام أوضح من قبل؟
- [ ] هل هناك حواف حادة؟
- [ ] هل التباين عالي بما يكفي؟

---

### المرحلة 2: الضبط اليدوي (10 دقائق)

```bash
python camera_tuner.py
```

**الخطوات:**
1. افتح نافذة الكاميرا
2. استخدم المفاتيح: B, C, S, E, F
3. ابحث عن أفضل مزيج
4. اكتب القيم عندما تكون مرضية
5. اضغط P لطباعة القيم
6. اضغط Q للخروج

**القيم الموصى بها حسب الإضاءة:**
```
إضاءة قوية:
- Brightness: 20-30
- Contrast: 120
- Exposure: -12

إضاءة عادية:
- Brightness: 45-50
- Contrast: 110-120
- Exposure: -8

إضاءة ضعيفة:
- Brightness: 60-80
- Contrast: 130
- Exposure: -4
```

---

### المرحلة 3: تطبيق القيم الجديدة (2 دقيقة)

عندما تجد قيماً جيدة:

1. افتح `camera_hd.py`
2. اذهب للسطر 66-70
3. استبدل القيم:
```python
cap.set(cv2.CAP_PROP_BRIGHTNESS, 45)    # ضع قيمتك
cap.set(cv2.CAP_PROP_CONTRAST, 110)     # ضع قيمتك
cap.set(cv2.CAP_PROP_SATURATION, 80)    # ضع قيمتك
cap.set(cv2.CAP_PROP_EXPOSURE, -8)      # ضع قيمتك
cap.set(cv2.CAP_PROP_FOCUS, 50)         # ضع قيمتك
```
4. احفظ الملف
5. أعد تشغيل الكاميرا

## 🔨 إذا لم يحسّن كثيراً

### جرب هذه الخطوات الإضافية:

**1. تحسين الإضاءة (أهم شيء):**
```
❌ لا: إضاءة الشمس المباشرة
❌ لا: ظل على الشاشة
✅ نعم: إضاءة بيضاء موحدة من جانب
✅ نعم: مصباح LED بجانب الكاميرا
```

**2. موضع الكاميرا:**
```
❌ لا: مقابل الشاشة مباشرة
❌ لا: على بعد 10 سم أو أقل
✅ نعم: على بعد 20-30 سم
✅ نعم: على جانب الشاشة بزاوية 45 درجة
```

**3. تثبيت الكاميرا:**
```
❌ لا: بيدك (حركة = ضبابية)
❌ لا: على سطح غير مستقر
✅ نعم: حامل ثابت (ترايبود)
✅ نعم: معدن أو خشب كثيف
```
