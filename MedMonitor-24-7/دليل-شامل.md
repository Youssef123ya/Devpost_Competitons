في Swagger:

## 🎓 الـ Alert Levels

### 🟢 Normal (95% ثقة)
- الأعراض: كل شيء تمام التمام
- الإجراء: استمر في المراقبة الروتينية

### 🟡 Warning (75-88% ثقة)
- الأعراض: قراءات مقلقة لكن ليست حرجة
- الإجراء: راقب المريض عن كثب

### 🔴 Critical (94-99% ثقة)
- الأعراض: حالة طارئة تحتاج تدخل فوري
- الإجراء: تنبيه الفريق الطبي فوراً

## 🔒 مسألة المصادقة

### المشكلة:
الـ API يحتاج `Bearer Token` لكن قد لا تملكه الآن.

### الحل المؤقت (للتطوير فقط):

**عدّل هذا الملف:**
```
Controllers/AIAlertController.cs
```

**أضف `[AllowAnonymous]`:**
```csharp
[AllowAnonymous]
[ApiController]
[Route("[controller]")]
public class AIAlertController : BaseController
```

**ثم شغل الخادم مجددا:**
```cmd
dotnet run
```

### ⚠️ تذكر:
**استبدل `[AllowAnonymous]` بـ `[Authorize]` قبل النشر على الإنتاج!**

## 🛠️ استكشاف الأخطاء

### ❌ "Connection refused"
- **السبب:** الخادم لا يعمل
- **الحل:** شغل `dotnet run` مجددا

### ❌ "404 Not Found"
- **السبب:** عنوان URL خاطئ
- **الحل:** استخدم بالضبط: `http://localhost:5140/AIAlert/Predict`

### ❌ "400 Bad Request"
- **السبب:** بيانات غير صحيحة
- **الحل:** تحقق من نطاقات البيانات

### ❌ "401 Unauthorized"
- **السبب:** بدون Bearer Token
- **الحل:** أضف `[AllowAnonymous]` مؤقتاً

### ❌ "500 Internal Server Error"
- **السبب:** خطأ في الخادم
- **الحل:** شاهد console output للتفاصيل

## 📱 تطبيق Flutter (التطبيق)

### المرحلة التالية:
بعد التأكد من عمل الـ API، يمكنك:

1. استخدام `Dio` library في Flutter
2. إنشاء model classes مطابقة
3. استدعاء endpoint من التطبيق

**مثال:**
```dart
final response = await Dio().post(
  'http://192.168.1.X:5140/AIAlert/Predict',
  data: {
    "heartRate": 75,
    "spO2": 97.5,
    "systolicBP": 120,
    "diastolicBP": 76,
    "temperature": 37.1
  }
);

print(response.data['data']['alertLevel']);  // Normal
```
