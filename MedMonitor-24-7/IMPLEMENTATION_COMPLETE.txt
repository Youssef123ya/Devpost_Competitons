🔗 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════

STREAM & DEBUG:
  GET http://localhost:8000/stream
      → Live MJPEG video (1920x1080, 30fps)

  GET http://localhost:8000/snapshot
      → Current JPEG frame

  GET http://localhost:8000/debug
      → Camera settings & metrics

  GET http://localhost:8000/config
      → Camera configuration


VITAL SIGNS API:
  GET http://localhost:5000/vital-signs/latest
      → Latest vital signs with confidence

  GET http://localhost:5000/vital-signs/health
      → API health status

  GET http://localhost:5000/vital-signs/status
      → OCR extraction status

📱 FLUTTER APP INTEGRATION
═══════════════════════════════════════════════════════════════════════════

1. GET SERVER IP:
   ipconfig → Look for IPv4 Address (e.g., 192.168.1.100)

2. UPDATE FLUTTER CONSTANTS:
   const String CAMERA_URL = "http://192.168.1.100:8000";
   const String API_URL = "http://192.168.1.100:5000";

3. IN FLUTTER CODE:
   // Stream
   Image.network("${CAMERA_URL}/stream")
   
   // Vitals
   http.get(Uri.parse("${API_URL}/vital-signs/latest"))

4. BUILD & RUN:
   flutter clean
   flutter pub get
   flutter build windows
   flutter run
