لقد قمت بتطوير **نظام متكامل وجاهز للعمل** لربط كاميرا USB (LOVEBAY 720P) مع تطبيق MedMonitor.

## ✨ الميزات الرئيسية

### 🎥 Live Video Streaming
```
USB Webcam → Python (OpenCV) → Flask Server (Port 8000)
                ↓
            MJPEG Stream
                ↓
        Flutter App + Web + Any Client
```

**المواصفات:**
- ✅ Resolution: 1280x720 (HD)
- ✅ FPS: 30 frames/sec
- ✅ Format: MJPEG
- ✅ Latency: < 500ms

### 📊 Vital Signs Extraction
يقرأ من شاشة المونيتور كل 5 ثواني:
- ❤️ **Heart Rate** (نبضات القلب)
- 🫁 **SpO2** (نسبة الأكسجين)
- 🩸 **Blood Pressure** (ضغط الدم)
- 🌡️ **Temperature** (درجة الحرارة)

### 🔗 Backend Integration
```
Vital Signs Data
        ↓
Python Service (Polling)
        ↓
.NET Backend API
        ↓
Database Storage + Alerts
```

### 📱 Flutter Integration
```dart
CameraStreamWidget(
  streamUrl: 'http://localhost:8000/stream',
  height: 400,
)
```

## 🚀 البدء السريع (3 خطوات)

### 1️⃣ وصّل الكاميرا
```
🔌 وصل USB Camera بـ USB Port
⏳ انتظر 3 ثواني (Windows يثبتها تلقائياً)
```

### 2️⃣ شغّل الخدمة
**Windows:**
- انقر مرتين على `START_CAMERA_SERVICE.bat`

**Linux/Mac:**
```bash
python camera_service.py
```

### 3️⃣ اختبر النظام
```bash
python test_camera_service.py
```

## 🌐 الـ API Endpoints

```
GET  http://localhost:8000/stream      → MJPEG Live Stream
GET  http://localhost:8000/snapshot    → صورة JPEG واحدة
GET  http://localhost:8000/vitals      → JSON بـ Vital Signs
GET  http://localhost:8000/health      → Status Check
GET  http://localhost:8000/config      → Camera Configuration
```

### مثال `/vitals`:
```json
{
  "heart_rate": 72,
  "spo2": 98,
  "blood_pressure": "120/80",
  "temperature": 36.8,
  "timestamp": "2026-05-24T11:30:00"
}
```
