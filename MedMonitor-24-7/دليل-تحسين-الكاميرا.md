## 🔍 ما إذا كانت القيم خاطئة

### 1️⃣ إذا كانت جميع القيم `null`

**تحقق من:**
- [ ] خدمة الكاميرا تعمل؟ → اختبر `http://localhost:8000/health`
- [ ] هل تظهر صورة في `http://localhost:8000/snapshot-enhanced`؟
- [ ] هل توجد رسائل خطأ في نافذة الكاميرا؟

**الحل:**
```bash
# أعد تشغيل الكاميرا
taskkill /IM python.exe /F
START_CAMERA_HD.bat
```

### 2️⃣ إذا كانت قيمة واحدة خاطئة

**مثال:** HR يقول 200 بدلاً من 127

**الحل:** اضبط منطقة ROI في `ocr_optimized.py`:
- اذهب إلى السطر 115-125
- غيّر إحداثيات `roi_map['hr']`

### 3️⃣ إذا كانت الصورة غير واضحة

**في ملف `camera_hd.py`:**

**لزيادة السطوع:**
```python
cap.set(cv2.CAP_PROP_BRIGHTNESS, 50)  # من 30 إلى 50
```

**لزيادة التباين:**
```python
cap.set(cv2.CAP_PROP_CONTRAST, 110)  # من 90 إلى 110
```

**لتقليل الإضاءة الزائدة:**
```python
cap.set(cv2.CAP_PROP_EXPOSURE, -10)  # من -6 إلى -10
```
