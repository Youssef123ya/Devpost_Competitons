## 🔐 مشكلة المصادقة (Authentication)

الـ API يحتاج `Bearer Token` افتراضياً.

### الحل المؤقت (للتطوير):

عدّل `AIAlertController.cs`:

```csharp
// قبل:
[Authorize]
public class AIAlertController

// بعد (للتطوير فقط):
[AllowAnonymous]
[ApiController]
[Route("[controller]")]
public class AIAlertController
```

## 📞 إذا واجهت مشاكل

### المشكلة: "Connection refused"
**الحل:** تأكد أن الخادم يعمل

### المشكلة: "401 Unauthorized"
**الحل:** أضف `[AllowAnonymous]` أو استخدم Bearer Token

### المشكلة: "400 Bad Request"
**الحل:** تحقق من نطاقات البيانات (SpO2: 0-100 إلخ)

### المشكلة: "500 Internal Error"
**الحل:** شاهد logs الخادم للمزيد من المعلومات
