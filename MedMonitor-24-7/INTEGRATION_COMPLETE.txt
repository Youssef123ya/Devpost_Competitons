📋 API ENDPOINTS REFERENCE
============================================================

Camera Service (localhost:8000):
  GET /stream
    → Live MJPEG video stream (continuous)
    → Use: Live display in Flutter widget

  GET /snapshot
    → Single JPEG frame
    → Use: OCR processing by extractor

  GET /health
    → {"status": "ok", "camera_running": true}
    → Use: Health check

Vital Signs API (localhost:5000):
  GET /vital-signs/latest
    → Latest extracted vital signs (JSON)
    → Response: {
        "timestamp": "2026-05-24T18:45:30.123Z",
        "vitals": {
          "hr": 82,
          "spo2": 98,
          "bp_sys": 120,
          "bp_dia": 80,
          "temp": 36.5
        },
        "confidence": {
          "hr": 0.85,
          "spo2": 0.85,
          "bp": 0.85,
          "temp": 0.85
        },
        "status": "success"
      }

  GET /vital-signs/health
    → Service status & data freshness
    → Use: Check if data is current

  GET /vital-signs/status
    → Extraction status (waiting/success/error)
    → Use: Display status to user

🔍 TROUBLESHOOTING QUICK TIPS
============================================================

Black screen in Flutter?
  → python find_usb_camera.py
  → Check: python find_usb_camera.py output
  → Verify camera_index.txt has "1"

No vital signs appearing?
  → Check vital_signs_latest.json exists
  → Verify ocr_vital_signs_extractor.py is running
  → Check vital_signs_api.py is responding: 
     curl http://localhost:5000/vital-signs/latest

Port already in use?
  → netstat -ano | findstr :8000
  → taskkill /PID <PID> /F
  → Then restart services

Services won't start?
  → pip install -r camera_requirements.txt --upgrade
  → Check Python version (3.8+)
  → Activate venv: venv\Scripts\activate.bat
