## 1️⃣ اختبار الصحة (Health Check)

**الطلب:**
```bash
GET http://localhost:5140/AIAlert/Health
```

**النتيجة المتوقعة (200 OK):**
```json
{
  "status": "healthy",
  "service": "AI Alert Prediction Service",
  "version": "1.0.0",
  "timestamp": "2024-05-19T21:22:44.123456Z"
}
```

**معايير النجاح:** ✅
- Status Code: 200
- الحقل `status` = "healthy"
- الخدمة موجودة

---

## 2️⃣ حالة عادية (Normal)

**الطلب:**
```json
{
  "heartRate": 75,
  "spO2": 97.5,
  "systolicBP": 120,
  "diastolicBP": 76,
  "temperature": 37.1,
  "fallDetected": false
}
```

**النتيجة المتوقعة (200 OK):**
```json
{
  "success": true,
  "data": {
    "alertLevel": "Normal",
    "confidence": 95.0,
    "reason": "All vital signs are within normal range.",
    "predictionTime": "2024-05-19T21:22:44.123456Z"
  }
}
```

**معايير النجاح:** ✅
- Status Code: 200
- alertLevel = "Normal"
- confidence = 95.0 (ممكن 90-95)
- reason يحتوي على "normal range"
- predictionTime موجود

## ❌ حالات الخطأ المتوقعة

### خطأ 1: بيانات ناقصة (400 Bad Request)

**الطلب:** (بدون `systolicBP`)
```json
{
  "heartRate": 95,
  "spO2": 96.5,
  "diastolicBP": 78,
  "temperature": 37.2,
  "fallDetected": false
}
```

**النتيجة المتوقعة (400 Bad Request):**
```json
{
  "message": "Invalid vital signs data",
  "errors": ["SystolicBP is required"]
}
```

**معايير النجاح:** ✅
- Status Code: 400
- message يحتوي على "Invalid"
- errors يحتوي على أسماء الحقول الناقصة

---

### خطأ 2: قيمة خارج النطاق (400 Bad Request)

**الطلب:** (SpO2 = 150، أكثر من 100)
```json
{
  "heartRate": 95,
  "spO2": 150,
  "systolicBP": 120,
  "diastolicBP": 78,
  "temperature": 37.2,
  "fallDetected": false
}
```

**النتيجة المتوقعة (400 Bad Request):**
```json
{
  "message": "Invalid vital signs data",
  "errors": ["SpO2 must be between 0 and 100"]
}
```

**معايير النجاح:** ✅
- Status Code: 400
- message يحتوي على "Invalid"
- errors يحتوي على معلومات النطاق الصحيح

---

### خطأ 3: بدون Authentication (401 Unauthorized)

**الطلب:** (بدون Authorization header)
```
POST /AIAlert/Predict
```

**النتيجة المتوقعة (401 Unauthorized):**
```json
{
  "message": "Unauthorized"
}
```

**معايير النجاح:** ✅
- Status Code: 401
- يُطلب إضافة Bearer token

## 📋 ملخص التحقق

**يجب أن تجد:**

✅ Health endpoint يرد
✅ Normal case يعيد "Normal"
✅ Warning case يعيد "Warning"
✅ Critical case يعيد "Critical"
✅ الثقة (Confidence) بين 75-98.5%
✅ الأسباب (Reason) واضحة ومفصلة
✅ الأخطاء معالجة بشكل صحيح (400, 401)
✅ الرسائل مفيدة وواضحة
✅ جميع التواريخ بصيغة ISO 8601
