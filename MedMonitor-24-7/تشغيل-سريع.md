## 🌐 افتح Swagger (الواجهة الرسومية)

بعد رؤية الرسالة أعلاه، افتح متصفحك واذهب إلى:


---

## 🧪 اختبر الـ API

في صفحة Swagger:

1. اضغط على **`GET /AIAlert/Health`**
2. اضغط **"Try it out"**
3. اضغط **"Execute"**

ستشاهد استجابة خضراء:
```json
{
  "status": "healthy",
  "service": "AI Alert Prediction Service"
}
```

---

## 🔴 اختبر حالة حرجة

1. اضغط على **`POST /AIAlert/Predict`**
2. اضغط **"Try it out"**
3. امسح ما بداخل Request body وانسخ:

```json
{
  "heartRate": 155,
  "spO2": 82,
  "systolicBP": 70,
  "diastolicBP": 45,
  "temperature": 40.5,
  "fallDetected": false
}
```

4. اضغط **"Execute"**

ستشاهد:
```json
{
  "alertLevel": "Critical",
  "confidence": 98.0,
  "reason": "Critical hypoxemia detected: SpO2 82%..."
}
```

## 💡 ملاحظات مهمة

- **الثقة (Confidence)** تختلف حسب الحالة
- **الأسباب (Reason)** تشرح الحالة بالتفصيل
- **الـ Alert Levels** ثلاث فقط: Normal, Warning, Critical

---

## 🎓 معنى النتائج

| Alert Level | المعنى | مثال |
|------------|--------|------|
| 🟢 Normal | كل شيء تمام | HR:75, SpO2:97% |
| 🟡 Warning | تنبيه - راقب | HR:125, SpO2:92% |
| 🔴 Critical | حرج - تدخل فوري | HR:155, SpO2:82% |
