## 🔨 الحلول حسب نوع المشكلة

### ❌ المشكلة: صورة ضبابية جداً

**السبب المحتمل:** التركيز الضعيف أو الحركة

**الحلول:**

**1. اضبط التركيز:**
```python
# في camera_hd.py السطر 65
cap.set(cv2.CAP_PROP_FOCUS, 80)  # جرب 0-100
```

**2. زيادة الإضاءة:**
```python
cap.set(cv2.CAP_PROP_BRIGHTNESS, 70)  # من 45 إلى 70
```

**3. استخدم حامل للكاميرا:**
- لا تمسك الكاميرا بيدك (الحركة تسبب ضبابية)
- استخدم حامل أو ترايبود

---

### ❌ المشكلة: صورة مظلمة جداً

**السبب المحتمل:** التعريض منخفض جداً أو إضاءة منخفضة

**الحلول:**

**1. قلل التعريض الناقص:**
```python
# في camera_hd.py السطر 64
cap.set(cv2.CAP_PROP_EXPOSURE, -4)  # من -8 إلى -4
```

**2. زيادة السطوع:**
```python
cap.set(cv2.CAP_PROP_BRIGHTNESS, 80)  # من 45 إلى 80
```

**3. أضف إضاءة بيضاء:**
- أضف مصباح LED بجانب الشاشة
- تأكد من أن الإضاءة موحدة (بدون ظلال)

---

### ❌ المشكلة: صورة مضاءة بشدة (overexposed)

**السبب المحتمل:** الإضاءة خلف الكاميرا قوية جداً

**الحلول:**

**1. قلل السطوع أكثر:**
```python
cap.set(cv2.CAP_PROP_BRIGHTNESS, 20)  # من 45 إلى 20
```

**2. اخفض التباين:**
```python
cap.set(cv2.CAP_PROP_CONTRAST, 80)  # من 110 إلى 80
```

**3. انقل الكاميرا:**
- تجنب الضوء المباشر من الشمس
- ضع الكاميرا على جانب الشاشة (ليس أمامها مباشرة)

---

### ❌ المشكلة: صورة غير حادة (soft)

**السبب المحتمل:** عدسة سيئة أو تركيز ضعيف

**الحلول:**

**1. عزز الشحذ:**
```python
# في camera_hd.py في دالة enhance_image()
# تم بالفعل زيادتها إلى 2.0!
```

**2. استخدم focus أقوى:**
```python
cap.set(cv2.CAP_PROP_FOCUS, 100)  # Max focus
```

**3. جرّب الحد الأدنى من المسافة:**
- ضع الكاميرا على بعد 20-30 سم من الشاشة
- جرب مسافات مختلفة (15-50 سم)

---

### ❌ المشكلة: صورة بها "موير" (moire pattern)

**السبب المحتمل:** تفاعل بين دقة الكاميرا و refresh rate الشاشة

**الحلول:**

**1. غيّر زاوية الكاميرا:**
- غيّر زاوية الكاميرا 5-10 درجات
- انقل الكاميرا قليلاً لليمين/اليسار

**2. استخدم تقنية deinterlacing:**
```python
# في camera_hd.py إضافة:
frame = cv2.deinterlace(frame, cv2.INTER_LINEAR)  # إذا كانت مدعومة
```

**3. غيّر FPS:**
```python
cap.set(cv2.CAP_PROP_FPS, 60)  # جرّب 60 بدلاً من 30
```

---

### ❌ المشكلة: الألوان غريبة/مشوهة

**السبب المحتمل:** توازن الأبيض (white balance) سيء

**الحلول:**

**1. تعطيل التوازن التلقائي:**
```python
cap.set(cv2.CAP_PROP_AUTO_WB, 0)  # Manual white balance
cap.set(cv2.CAP_PROP_WB_TEMPERATURE, 4000)  # 4000K (مصباح LED)
```

**2. في الإضاءة البيضاء:**
- استخدم مصابيح LED بيضاء (5000K)
- تجنب مصابيح صفراء (3000K)

## 🔍 كيفية قياس الجودة

### الجودة الممتازة:
```
✅ أرقام واضحة جداً
✅ حواف حادة
✅ تباين عالي (أبيض على أسود)
✅ لا ضبابية
✅ لا موير pattern
✅ ألوان طبيعية
```

### الجودة المقبولة:
```
✅ أرقام قابلة للقراءة
✅ حواف واضحة
✅ تباين جيد
⚠️ قد يكون هناك قليل من الضبابية
```

### الجودة السيئة:
```
❌ أرقام غير واضحة
❌ حواف ضبابية
❌ تباين منخفض
❌ لا يمكن قراءة الأرقام
```
