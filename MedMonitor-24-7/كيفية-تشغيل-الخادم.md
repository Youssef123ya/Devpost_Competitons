### الطريقة 3: استخدام cURL

#### اختبر الصحة أولاً:
```bash
curl http://localhost:5140/AIAlert/Health
```

**النتيجة المتوقعة:**
```json
{
  "status": "healthy",
  "service": "AI Alert Prediction Service",
  "version": "1.0.0",
  "timestamp": "2024-05-19T21:22:44.123Z"
}
```

#### اختبر التنبؤ (حالة عادية):
```bash
curl -X POST "http://localhost:5140/AIAlert/Predict" ^
  -H "Content-Type: application/json" ^
  -d "{""heartRate"": 75, ""spO2"": 97.5, ""systolicBP"": 120, ""diastolicBP"": 76, ""temperature"": 37.1, ""fallDetected"": false}"
```

**النتيجة المتوقعة:**
```json
{
  "success": true,
  "data": {
    "alertLevel": "Normal",
    "confidence": 95.0,
    "reason": "All vital signs are within normal range.",
    "predictionTime": "2024-05-19T21:22:44.123Z"
  }
}
```

## ✅ ماذا تتوقع من النتائج

### الاستجابة الناجحة (200 OK):
```json
{
  "success": true,
  "data": {
    "alertLevel": "Normal|Warning|Critical",
    "confidence": 75.0-98.5,
    "reason": "Description of why this alert level",
    "predictionTime": "2024-05-19T21:22:44.123456Z"
  }
}
```

### خطأ في البيانات (400 Bad Request):
```json
{
  "message": "Invalid vital signs data",
  "errors": ["SpO2 must be between 0 and 100"]
}
```

### عدم التفويض (401 Unauthorized):
```json
{
  "message": "Unauthorized"
}
```

## 🔍 معايير التحقق من الصحة

✅ **API يرد بـ 200 OK** للطلبات الصحيحة

✅ **جميع الحقول موجودة** في الاستجابة:
   - alertLevel
   - confidence
   - reason
   - predictionTime

✅ **Confidence بين 0 و 100**

✅ **Reason غير فارغ** (يشرح سبب التنبؤ)

✅ **Alert levels صحيحة**: Normal أو Warning أو Critical فقط

✅ **Reason يحتوي على معلومات مفيدة** عن الحالة

## 🐛 استكشاف الأخطاء

### المشكلة: "Connection refused"
**السبب:** الخادم لا يعمل
**الحل:** شغل `RUN_API.bat` أولاً

### المشكلة: "404 Not Found"
**السبب:** عنوان URL خاطئ
**الحل:** استخدم بالضبط: `http://localhost:5140/AIAlert/Predict`

### المشكلة: "400 Bad Request"
**السبب:** بيانات غير صحيحة
**الحل:** تحقق من أن جميع الحقول في النطاقات الصحيحة:
- heartRate: 0-300
- spO2: 0-100
- systolicBP: 0-300
- diastolicBP: 0-200
- temperature: 35-43

### المشكلة: "500 Internal Server Error"
**السبب:** خطأ في الخادم
**الحل:** شاهد سجلات الخادم (console output)
