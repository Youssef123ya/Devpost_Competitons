# 📝 دليل استخدام نظام طلبات دخول المرضى

## 🎯 الأهداف المحققة

تم بناء نظام متكامل لإدارة طلبات دخول المرضى يتضمن:

1. ✅ **شاشة إرسال الطلب من الدكتور** - تحتوي على جميع البيانات المطلوبة
2. ✅ **عرض الطلبات عند الأدمن** - مع جميع التفاصيل
3. ✅ **تتبع حالة الطلب عند الدكتور** - Pending/Approved/Rejected

---

## 👨‍⚕️ خطوات الدكتور

### الخطوة 1: الوصول لشاشة إضافة مريض
```
الشاشة الرئيسية → اضغط زر "Add New Patient"
أو
القائمة السفلية → الخيار الأول (Home) → اضغط "Add New Patient"
```

### الخطوة 2: ملء بيانات المريض
الاستمارة تحتوي على الحقول التالية:

| الحقل | النوع | ملاحظات |
|------|------|--------|
| Name | نص | اسم المريض الكامل |
| ID | نص | رقم الهوية الوطنية |
| Age | رقم | العمر بالسنوات |
| Gender | اختيار | ذكر / أنثى |
| Height | نص | الطول (سم) |
| Illness | نص | الحالة المرضية |
| Companion Phone | نص | رقم هاتف المرافق |
| Nurse Name | نص | اسم الممرضة المسؤولة |

### الخطوة 3: إرسال الطلب
- اضغط على زر **"Send Request"**
- سيظهر loading أثناء الإرسال
- بعد النجاح: رسالة "تم إرسال طلب الدخول بنجاح!"

---

## 👨‍💼 خطوات المسؤول (Admin)

### الوصول لقائمة الطلبات المعلقة
```
الشاشة الرئيسية → أنقر على "Pending Admission Requests"
أو
من القائمة الجانبية
```

### عرض تفاصيل الطلب
كل كارت طلب يحتوي على:
- **اسم الدكتور** (في الأعلى)
- **بيانات المريض**: الاسم، العمر، الجنس، الطول
- **البيانات الطبية**: الحالة، الهوية
- **معلومات الاتصال**: هاتف المرافق، اسم الممرضة
- **الوقت**: متى تم إرسال الطلب

### إجراء إجراء على الطلب
- اضغط على الكارت للمزيد من الخيارات
- يمكنك: الموافقة / الرفض / طلب معلومات إضافية

---

## 👨‍⚕️ تتبع حالة الطلب (جديد)

### الوصول لشاشة حالة الطلبات
```
الشاشة الرئيسية → القائمة السفلية → الخيار الثالث (طلبات الدخول)
```

### فهم حالات الطلبات

#### 1️⃣ قيد الانتظار (Pending) 🟠
```
الأيقونة: ⏳ (ساعة)
اللون: برتقالي
المعنى: الطلب تم إرساله والأدمن لم يقرر بعد
```

#### 2️⃣ موافق عليه (Approved) 🟢
```
الأيقونة: ✓ (علامة صح)
اللون: أخضر
المعنى: تمت الموافقة على دخول المريض
```

#### 3️⃣ مرفوض (Rejected) 🔴
```
الأيقونة: ✗ (إلغاء)
اللون: أحمر
المعنى: تم رفض طلب الدخول
```

## 📊 مثال عملي

### سيناريو كامل:

#### الدكتور أحمد:
1. دخل التطبيق
2. ضغط "Add New Patient"
3. ملأ البيانات:
   - اسم: محمد علي
   - الهوية: 1234567890
   - العمر: 45 سنة
   - الجنس: ذكر
   - الطول: 180 سم
   - الحالة: ارتفاع ضغط الدم
   - هاتف المرافق: 0501111111
   - الممرضة: فاطمة احمد
4. ضغط "Send Request"
5. ✅ تم الإرسال

#### الأدمن:
1. ذهب لـ "Pending Admission Requests"
2. رأى طلب جديد من د. أحمد
3. رأى جميع البيانات مباشرة في الكارت
4. قرر الموافقة على الطلب

#### الدكتور أحمد (متابعة):
1. دخل التطبيق
2. ضغط على تبويب "Admission Status" 
3. رأى طلبه مع الحالة: **✓ موافق عليه** (أخضر)
4. معرفة أن المريض محمد علي تمت الموافقة على دخوله

## 🐛 استكشاف الأخطاء

### المشكلة: لا ترى الطلبات المرسلة
**الحل:**
- تأكد من الاتصال بالإنترنت
- حاول تحديث الصفحة (Pull to refresh)
- قد تكون البيانات محفوظة محلياً

### المشكلة: الزر "Send Request" معطل
**الحل:**
- تأكد من ملء الحقول المهمة (الاسم والعمر)
- تحقق من الاتصال بالإنترنت
- أعد فتح التطبيق

### المشكلة: لم تظهر الحالة (Approved/Rejected)
**الحل:**
- انتظر قليلاً (قد يستغرق عدة دقائق)
- اضغط زر الـ Refresh
- تأكد من أن الأدمن وافق/رفض الطلب
