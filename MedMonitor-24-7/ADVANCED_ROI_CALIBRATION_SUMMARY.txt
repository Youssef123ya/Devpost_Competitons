========================================
🆕 NEW FEATURES
========================================

1. ✅ VISUAL ROI LABELS
   Shows what you're calibrating:
   "Calibrate: HR [1/7]"
   
   Helps avoid confusion about which vital
   sign is being selected

2. ✅ AUTOMATIC PREVIEW
   After dragging/releasing:
   - Shows selected region in new window
   - Can see exactly what was captured
   - Press any key to continue
   
   Advantage: Catch mistakes before OCR

3. ✅ OCR TEST MODE ('t' key)
   Press 't' while selecting to test OCR:
   
   Output shows:
   - ✅ Text detected (e.g., "107")
   - 📊 Confidence: 0.95
   - 📝 Per-character confidence:
        • '1' (conf: 0.96)
        • '0' (conf: 0.94)
        • '7' (conf: 0.95)
   
   Advantage: Know if OCR will work BEFORE
   saving the ROI

4. ✅ DEBUG IMAGE SAVING
   Auto-saves to debug_rois/{vital}/
   
   Files:
   - 01_original_roi.jpg
      Raw area you selected
   
   - 02_processed_roi.jpg
      After vital-specific preprocessing
      (color masking, thresholding, upscaling)
   
   Advantage: Visual debugging! See exactly
   what OCR is reading

5. ✅ COLOR-SPECIFIC PREPROCESSING
   Different for each vital:
   
   • HR/Pulse:
     HSV green mask + threshold + 3x scale
   
   • SpO2:
     HSV white+yellow mask + CLAHE + 3x
   
   • etCO2:
     HSV yellow mask + threshold + 3x
   
   • RR:
     4x upscale + CLAHE + threshold
   
   • Temp:
     CLAHE + preserve decimals + 3x
   
   • NBP:
     Default CLAHE + threshold
   
   Advantage: Optimal OCR accuracy per type

========================================
🛠️ TROUBLESHOOTING
========================================

Problem: GUI won't open
└─ Run: FIX_OPENCV_GUI.bat
└─ Verify: python -c "import cv2; cv2.imshow"

Problem: 't' key shows "OCR not available"
└─ Install: pip install easyocr
└─ Retry: python roi_calibration_tool_advanced.py

Problem: Debug images don't show text clearly
└─ Re-select ROI with better positioning
└─ Ensure camera is in focus
└─ Check monitor display brightness

Problem: Text shows but confidence < 0.5
└─ ROI probably too small
└─ Expand selection area
└─ Or includes overlapping numbers

Problem: Debug images not appearing
└─ Check folder: debug_rois/
└─ Permissions issue? mkdir debug_rois manually
└─ Retry calibration
