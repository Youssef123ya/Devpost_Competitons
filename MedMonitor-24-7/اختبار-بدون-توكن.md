# 🔓 اختبار بدون Authentication (لأغراض التطوير)

## المشكلة ✋

الـ API يحتاج `Bearer Token` لكن قد لا تملكه الآن.

## الحل 💡

يمكنك تعديل `AIAlertController.cs` **مؤقتاً** لتجاوز المصادقة أثناء التطوير.

---

## الخطوة 1: افتح الملف

```
MedMonitor/Controllers/AIAlertController.cs
```

---

## الخطوة 2: ابحث عن هذا السطر

```csharp
[Authorize]
public class AIAlertController : BaseController
```

## الخطوة 3: أضف `[AllowAnonymous]`

اجعله هكذا:

```csharp

[ApiController]
```

**لا تنسَ إعادة الـ `[Authorize]`** قبل النشر على الإنتاج!

```csharp
[Authorize]  // ✅ يجب أن يكون موجود
```

## 📝 الملف الأصلي

إذا أخطأت، إليك النسخة الأصلية:

```csharp
using MedMonitor.Core.Dto;
using MedMonitor.Core.Interfaces;
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;

namespace MedMonitor.Controllers
{
    /// <summary>
    /// AI Alert Prediction Controller
    /// Handles patient vital signs analysis and alert prediction
    /// </summary>
    [Authorize]
    [ApiController]
    [Route("[controller]")]
    public class AIAlertController : BaseController
    {
        private readonly IAIAlertService _aiAlertService;
        private readonly ILogger<AIAlertController> _logger;

        public AIAlertController(IAIAlertService aiAlertService, ILogger<AIAlertController> logger)
        {
            _aiAlertService = aiAlertService;
            _logger = logger;
        }

        [HttpPost("Predict")]
        [ProducesResponseType(StatusCodes.Status200OK)]
        [ProducesResponseType(StatusCodes.Status400BadRequest)]
        [ProducesResponseType(StatusCodes.Status401Unauthorized)]
        [ProducesResponseType(StatusCodes.Status500InternalServerError)]
        public async Task<IActionResult> PredictAlertLevel([FromBody] AiPredictionRequestDto request)
        {
            try
            {
                if (!ModelState.IsValid)
                {
                    _logger.LogWarning("Invalid vital signs data received");
                    return BadRequest(new
                    {
                        message = "Invalid vital signs data",
                        errors = ModelState.Values.SelectMany(v => v.Errors.Select(e => e.ErrorMessage))
                    });
                }

                _logger.LogInformation($"Processing AI alert prediction for user: {CurrentUserId}");

                var prediction = await _aiAlertService.PredictAlertLevelAsync(request);

                return Ok(new
                {
                    success = true,
                    data = prediction
                });
            }
            catch (Exception ex)
            {
                _logger.LogError($"Error during prediction: {ex.Message}");
                return StatusCode(500, new
                {
                    message = "An error occurred during prediction",
                    error = ex.Message
                });
            }
        }

        [HttpGet("Health")]
        [AllowAnonymous]
        [ProducesResponseType(StatusCodes.Status200OK)]
        public IActionResult GetHealth()
        {
            return Ok(new
            {
                status = "healthy",
                service = "AI Alert Prediction Service",
                version = "1.0.0",
                timestamp = DateTime.UtcNow
            });
        }
    }
}
```

## 🎯 الخيارات

### الخيار 1: لا تعديل (الأفضل للإنتاج)
- استخدم `Bearer Token` من تسجيل الدخول
- أكثر أماناً

### الخيار 2: إضافة `[AllowAnonymous]` (للتطوير)
- اختبار سريع بدون توكن
- فقط أثناء التطوير!

### الخيار 3: استخدم PostMan مع Bearer Token
- الطريقة الاحترافية
- ستحتاج توكن من `/Login` endpoint
