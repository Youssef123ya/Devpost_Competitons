### الطريقة 3️⃣: استخدام PowerShell/CMD يدويـاً

#### ✅ اختبار 1: Health Check
```powershell
$uri = "http://localhost:5140/AIAlert/Health"
Invoke-RestMethod -Uri $uri -Method Get
```

#### ✅ اختبار 2: حالة عادية (Normal)
```powershell
$uri = "http://localhost:5140/AIAlert/Predict"
$body = @{
    heartRate = 75
    spO2 = 98
    systolicBP = 120
    diastolicBP = 80
    temperature = 37.0
} | ConvertTo-Json

Invoke-RestMethod -Uri $uri -Method Post -Body $body -ContentType "application/json"
```

**النتيجة المتوقعة:**
```json
{
  "success": true,
  "data": {
    "alertLevel": "Normal",
    "confidence": 94.5,
    "reason": "All vital signs are within normal ranges."
  }
}
```

## 🔧 استكشاف الأخطاء

### ❌ الخطأ: "Port 5140 already in use"
```bash
# اقتل عملية موجودة
netstat -ano | findstr :5140
taskkill /PID <PID> /F
```

### ❌ الخطأ: "dotnet not found"
تأكد من تثبيت .NET 8 SDK: https://dotnet.microsoft.com/download

### ❌ الخطأ: "Unauthorized"
تأكد من أن endpoint Predict يحتوي على `[AllowAnonymous]` (تم إضافته بالفعل)

## 📚 Endpoints المتاحة

| الطريقة | المسار | الوصف | التوكن مطلوب |
|---------|-------|-------|------------|
| GET | `/AIAlert/Health` | التحقق من صحة الخدمة | ❌ لا |
| POST | `/AIAlert/Predict` | التنبؤ بمستوى التنبيه | ❌ لا |

## 💡 ملاحظات مهمة

1. **التنبؤ قائم على القواعد**: التطبيق يستخدم منطق قائم على القواعد (وليس ML) مناسب لمشروع التخرج
2. **لا يوجد مصادقة مطلوبة**: تم إزالة متطلب التوكن لسهولة الاختبار
3. **البيانات المدخلة**:
   - HeartRate: نبضات القلب (70-100 طبيعي)
   - SpO2: تشبع الأكسجين (95-100 طبيعي)
   - SystolicBP: ضغط انقباضي (90-120 طبيعي)
   - DiastolicBP: ضغط انبساطي (60-80 طبيعي)
   - Temperature: درجة الحرارة (36.5-37.5 طبيعي)
   - FallDetected: كشف السقوط (اختياري، قيمة boolean)
