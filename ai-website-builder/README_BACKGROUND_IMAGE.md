# ميزة تحديث صورة الخلفية - Background Image Update Feature

## 🎯 ما هي الميزة؟

تحديث صورة خلفية البطل (Hero) مباشرة من صفحة المعاينة مع ظهور التحديث فوراً دون الحاجة لتحديث الصفحة.

---

## ✨ المميزات الرئيسية

| المميزة | الوصف |
|--------|-------|
| 🚀 **التحديث الفوري** | تحديث فوري في المعاينة دون تحديث الصفحة |
| 🎨 **واجهة جميلة** | واجهة بديهية وسهلة الاستخدام |
| 🔄 **التحديث التلقائي** | حذف الصور القديمة تلقائياً |
| 💾 **الحفظ التلقائي** | حفظ تلقائي في قاعدة البيانات والتخزين |
| 🔒 **آمن جداً** | تحقق من الملفات والأمان والمصادقة |
| 📱 **متجاوب** | يعمل على جميع أحجام الشاشات |
| ⚡ **سريع** | رفع سريع وتحديث فوري |

---

## 🚀 البدء السريع

### 1. الذهاب إلى صفحة المعاينة
```
http://localhost:8000/hero/{heroId}/generate
```

### 2. البحث عن قسم "Background Image"
في الـ Sidebar على اليسار

### 3. اختيار الصورة
- اضغط على الصورة أو منطقة التحميل
- اختر صورة من جهازك

### 4. الانتظار والتحديث
الصورة ستظهر فوراً في المعاينة

## 🔧 التفاصيل التقنية

### الـ Endpoint

```http
POST /hero/{heroId}/update-background-image

Headers:
  Content-Type: multipart/form-data
  X-CSRF-TOKEN: your_csrf_token

Body:
  background_image: <file>
```

### الاستجابة (نجاح)

```json
{
  "success": true,
  "message": "Background image updated successfully",
  "image_url": "/storage/heroes/hero12345.jpg",
  "image_path": "heroes/hero12345.jpg"
}
```

### الاستجابة (خطأ)

```json
{
  "success": false,
  "message": "Failed to update background image: error details"
}
```

## 🐛 حل المشاكل

### المشكلة: الصورة لا تظهر
**الحل**:
1. تأكد من وجود صلاحيات المجلد: `chmod 755 storage/app/public`
2. تأكد من الـ symlink: `php artisan storage:link`
3. تحقق من حجم الصورة (أقل من 5 MB)

### المشكلة: الرسالة "Invalid file"
**الحل**:
1. تأكد من أن الملف صورة حقيقية
2. استخدم صيغ مدعومة: JPEG, PNG, GIF, WebP
3. جرب صورة أخرى

### المشكلة: الصورة تم رفعها لكن لا تظهر
**الحل**:
1. حدث الصفحة (F5)
2. مسح كاش المتصفح
3. حاول في متصفح آخر
